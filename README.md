# Personal Portfolio

A modern personal portfolio website built with Next.js to showcase projects, skills, and contact information in a clean and professional way.

## Overview

This portfolio is designed to help visitors quickly learn about my background, view my work, and get in touch for collaborations or opportunities. The site includes a polished landing page with sections for introduction, skills, projects, and contact details.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Then open http://localhost:3000 to view the site locally.

## Purpose

This project serves as a digital resume and personal brand presence, making it easier to present my work and professional profile online.
